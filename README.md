# Hotel Analytics ETL Pipeline

An ETL pipeline using the Bronze-Silver-Gold (medallion) architecture to clean and
model synthetic hotel booking data, loading each layer into PostgreSQL. Runs via
Docker end to end — database and pipeline included.

## Architecture

```
data/*.csv (raw, messy)
      │
      ▼
  BRONZE   bronze_bookings, bronze_guests, bronze_hotels, bronze_rooms
           unprocessed data, loaded as-is
      │
      ▼
  SILVER   silver_bookings, silver_guests, silver_hotels, silver_rooms
           deduplicated, type-cast, normalized (casing/whitespace),
           data-quality checks applied
      │
      ▼
  GOLD     bookings, guests, hotels, rooms
           final tables with PK/FK constraints (see sql/schema.sql),
           also exported as CSV to output/*_gold.csv
```

Rows that fail data-quality checks (invalid `nights`, `total_revenue` not
matching `nights × rate_per_night`) are flagged and written to
`output/rejected_rows.csv` instead of silently dropped.

## Project structure

```
scripts/
  pipeline.py         the ETL pipeline: bronze -> silver -> gold
sql/
  schema.sql          gold-layer table definitions (PKs, FKs, constraints)
  queries.sql         analysis queries against the gold tables
data/                 raw input CSVs (generated by generate-data.py)
output/               gold-layer CSV exports + rejected_rows.csv
Dockerfile            image for running pipeline.py
docker-compose.yml    postgres + pipeline services
```

## Setup

1. Copy the environment template and fill in values:
   ```bash
   cp .env.example .env
   ```
2. Start Postgres:
   ```bash
   docker compose up -d postgres
   ```
3. Run the pipeline (builds the image if needed):
   ```bash
   docker compose run --rm pipeline
   ```

This loads bronze, silver, and gold tables into Postgres and writes the gold
CSV exports to `output/`.

## Running queries

Connect with `psql` from the host:
```bash
psql -h localhost -p <POSTGRES_PORT> -U <POSTGRES_USER> -d <POSTGRES_DB> -f sql/queries.sql
```

Or from inside the container:
```bash
docker exec -it hotelprj-container psql -U <POSTGRES_USER> -d <POSTGRES_DB>
```

## Regenerating source data

```bash
python scripts/generate-data.py
```

## Local (non-Docker) pipeline runs

```bash
pip install -r requirements.txt
python scripts/pipeline.py
```

Requires `POSTGRES_HOST`/`HOST` in `.env` to point at wherever Postgres is
reachable (`localhost` if run outside Docker).
